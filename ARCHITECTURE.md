# PaperDesk implementation contract

Package `paperdesk`, Qt Widgets GUI in `paperdesk/ui/`, modules backend.py, simulator.py, installer.py, art.py, models.py. Entrypoint `python -m paperdesk`, flag `--demo` starts a disposable simulated tablet without network access. Default startup disconnected; never auto-install or reconnect to a physical tablet.

Backend/UI boundary is a `SuiteService` class (backend.py). `SuiteService.demo(root: Path|None=None)` and constructor `SuiteService(config: DeviceConfig)`; config has host (default 10.11.99.1), port=22, username=root, key_path='', password='', state_dir=optional Path. Password is memory-only. Explicit pairing must show an observed SHA256 host fingerprint, then store trust on user confirmation before authenticating. Do not silently trust unknown or changed hosts.

Methods all synchronous, called by GUI worker: `connect()->dict`, `disconnect()->None`, `status()->dict`, `documents()->list[dict]`, `upload(path: str, folder: str='')->dict`, `download(document_id: str, destination: str)->dict`, `export_current(destination: str)->dict`, `screenshot(destination: str)->dict`, `type_text(text: str)->dict`, `send_key(key: str)->dict`, `paste_image(path: str)->dict`, `add_page(template: str)->dict`, `refresh()->dict`, `sync(folder: str)->dict`, `installer_plan(features: list[str])->dict`, `install(features: list[str])->dict`, `uninstall()->dict`, `diagnostics()->dict`, `start_art(application: str='krita', options: dict|None=None)->dict`, `stop_art()->dict`, `open_art(application: str, path: str='')->dict`. Feature IDs: keyboard, touch, direct-paste, art-display. Template IDs: cornell, grid, lined, blank. Key IDs: backspace, erase-five, enter, tab, escape, copy, paste, close, left, right, up, down.

Returned dicts JSON serializable. status/connect: connected, simulated, model, firmware, host, transport, capabilities (dict booleans), active_document (dict with id,name,page,pages), message. documents: id,name,type,pages,modified,folder. mutation result: ok, message and additional operation-specific details (path,id,state,etc). Unknown mutation raises a distinct exception explaining no retry. Exceptions are safe actionable messages. install plans enumerate changes and compatibility; installer refuses when unsupported. GUI should display results, never fake completion.

Installer API: `DeviceInstaller(transport, state_dir: Path)`, `probe()->dict`, `plan(features: list[str])->dict`, `install(features: list[str])->dict`, `uninstall()->dict`. Transport API `run(script: str, timeout: float=30)->str`, `read_bytes(path: str)->bytes`, `write_bytes(path: str,data: bytes,mode: int=0o600)->None`, `exists(path: str)->bool`. Installation must only write app-owned paths /home/root/.local/lib/paperdesk and volatile /run configuration. For injected extension support preserve pre-existing loader config and extensions and use the original guarded deployment flow or equivalent; never overwrite other app config.

Simulator API: `TabletSimulator(root: Path|None=None, model: str='paper-pro', firmware: str='3.28.0.172')`, with transport API above; `status()`, `documents()`, `upload(path,folder='')`, `download(id,destination)`, `export_current(destination)`, `screenshot(destination)`, `type_text(text)`, `send_key(key)`, `paste_image(path)`, `add_page(template)`, `refresh()`, `sync(folder)`, `diagnostics()`, `reboot()`, `set_fault(name,enabled=True)`. It must expose installer effects in status, preserve root confinement including symlinks, include fixtures for Paper Pro and reMarkable 2, and record operations. No proprietary firmware/binaries/real documents. A behavioral simulator is not hardware emulation; document that clearly. Simulator keys do not send real SSH and demo should visually read Simulation.

Art API: `ArtManager(config, transport=None, simulated=False)`, `applications()->list[dict]`, `open(application,path='')->dict`, `start(application='krita',options=None)->dict`, `stop()->dict`, `status()->dict`. Native Linux pressure/tilt bridge can reuse existing source and compiled helper under vendor/art; other systems need a supported implementation or an explicit capability limit. Never say pointer-only is full pressure support. Krita/Inkscape/Blender can launch/open files on all platforms. Krita plugin installation is explicit and preserves originals. Commands are argv arrays without shell. No background streaming when idle.

Publishing: new public repository gjabdelnoor/paperdesk, original code AGPL-3.0-or-later with dependency notices, no personal/private fixtures. Native standalone builds on GitHub Actions Linux/Windows/macOS, simulator smoke and GUI smoke on each, zip/app artifacts and versioned prerelease. Verify build artifacts and tests before claiming platform support. No paid provisioning.
